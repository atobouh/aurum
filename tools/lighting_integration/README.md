# Development lighting replay

These scripts issue commands only through the development bridge, which rejects every save except the exact name **Aurum Lighting Audit**. Use a disposable copy. They alter blocks, entities, inventory, time and Aurum settings in that copy. Never rename an important save to bypass this guard.

Start the documented scenery profile under `runClient`, open the disposable save, and prepare the room with `tools/visual_lab/lighting_contract.mcfunction`. Use a 1280×720 X11 desktop, Python 3, ImageMagick `import`, FFmpeg and xdotool. Set `DISPLAY`, optionally `AURUM_XDOTOOL`, and `AURUM_LIGHTING_EVIDENCE` to an output directory.

1. With LambDynamicLights temporarily outside `run/mods`, run `python3 tools/lighting_integration/static_tests.py`. The elevated exact-count fixture is generated by the script.
2. Stop the client cleanly, restore LambDynamicLights, restart/open the same disposable save, then run `python3 tools/lighting_integration/compat_tests.py`.
3. Restore the original Aurum/options configuration after testing.

Captures include PNG hashes and actual diagnostic snapshots. Motion clips include raw per-frame telemetry. These scripts collect evidence; manual image/motion review and target-device frame-time tests remain necessary. The compatibility script explicitly asserts static voxel lighting is paused. It does not validate voxel-occluded moving lights.

Run `python3 tools/lighting_integration/verify_evidence.py` against the same evidence directory to validate exact source counts, actual motion, the held-light floor control and decoded video integrity. Manual cave/profile/UI review notes are retained when that file already exists. To regenerate the standalone report and the offline ZIP package, install `markdown2`, then run `python3 tools/render_shared_lighting_review.py --evidence /path/to/evidence`. The ZIP is written to `dist/aurum-0.6.2-alpha.1-lighting-report.zip`; extract all and open `Aurum-lighting-report/index.html`. It includes the original PNGs, WebM clips and evidence JSON and needs no network access to display its media.

The report additionally includes manual natural-dripstone and inventory checks. The cave camera is at player position `-1155.5 80 3897.5`, yaw `180`, pitch `-12`, creative mode, no night vision, time `1362000`; empty hand and held torch are paired. The wider forest camera is `2583.5 119 3328.5`, yaw `90`, pitch `15`, time `1350000`. These coordinates belong to the disposable generated scenery profile, not the user's original save. The cave result is unresolved and must not be promoted to a passing acceptance test by the automated verifier.
